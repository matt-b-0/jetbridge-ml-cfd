1. The report in one minute

Question: can sparse sensor measurements reconstruct air speed across a jet bridge, and does SVR improve on simpler interpolation?

Workflow: read measured speeds → hide one sensor → fit the retained sensors → predict the hidden speed → compare errors.

Inputs are sensor positions in metres and scalar speeds in m/s. Outputs are predicted speeds, held-location errors and a mask showing spatial support. The study uses 36 averaged files and 504 sensor means from one apparatus.

MethodMean per-run RMSE (m/s)
Mean baseline0.06765
Nearest neighbour0.07129
Linear0.05524
Thin-plate RBF0.04959
SVR0.05774

RBF has the lowest aggregate error, but its advantage concentrates at the 58 ft station.

These scores use the same 360 supported targets. Linear cannot extrapolate; the other 144 targets are reported separately. The sensor hull is the polygon enclosing known sensor positions. More than half of the physical section lies outside that hull in the illustrated layouts. Smooth maps do not establish accuracy there.

Report pages 6–9 provide supporting CFD, sensitivity and timing evidence. CFD is a separate numerical reference, with unresolved physical bias. The thermal extension is unconverged and excluded from trusted training/reference data.

def read_speed_average(path: str | Path) -> pd.DataFrame:
    """Read one numeric-station FAA BLOCK file.

    Parameters
    ----------
    path : str or Path
        V-Sxx-setup-station-flow-replicate.txt in 03-Averages.

    Returns
    -------
    pandas.DataFrame
        Absolute metre coordinates, speed in m/s, source row and run metadata.
        Missing speed sentinels become NaN; invalid coordinates are rejected.
    """
    path = Path(path)
    match = re.fullmatch(
        r"V-(S\d+)-([A-Z0-9]+)-(\d+)-(HN|HP|LN|LP)-(\d+[A-Z]?)", path.stem)
    if not match:
        raise ValueError(f"Unsupported replicate filename: {path.name}")
    text = path.read_text(encoding="cp1252")
    variables = re.search(r"(?m)^VARIABLES=(.*)$", text)
    zones = list(re.finditer(r"(?m)^ZONE\s+(.*)$", text))
    if variables is None or len(zones) != 1:
        raise ValueError("Expected VARIABLES and exactly one ZONE")
    names = re.findall(r'"([^"]+)"', variables[1])
    expected = ["X (m)", "Y (m)", "Z (m)", "Mean", "dMean", "Median", "dMedian", "StdDev"]
    if names != expected:
        raise ValueError(f"Unexpected units/variables: {names}")
    header = zones[0][1]
    dims = [re.search(rf"\b{axis}\s*=\s*(\d+)", header) for axis in "IJK"]
    if not all(dims) or not re.search(r"\bF\s*=\s*BLOCK\b", header):
        raise ValueError("Expected I/J/K dimensions and F=BLOCK")
    count = int(np.prod([int(dim[1]) for dim in dims]))
    tokens = text[zones[0].end():].split()
    values = np.array([float(token) for token in tokens])
    if count < 4 or values.size != count * len(names):
        raise ValueError("BLOCK data length does not match dimensions")
    data = values.reshape(len(names), count)
    xyz = data[:3].T
    if not np.isfinite(xyz).all() or np.any(xyz == -9999):
        raise ValueError("Invalid sensor coordinates")
    if np.unique(xyz, axis=0).shape[0] != count or np.ptp(xyz[:, 2]) > 1e-9:
        raise ValueError("Expected unique coordinates on one z plane")
    speed = data[3].copy()
    speed[speed == -9999] = np.nan
    if np.isinf(speed).any() or np.any(speed[np.isfinite(speed)] < 0):
        raise ValueError("Invalid negative/infinite speed")
    config, setup, station, flow, replicate = match.groups()
    frame = pd.DataFrame(xyz, columns=["x_m", "y_m", "z_m"])
    frame["speed_mps"] = speed
    frame["source_row"] = np.arange(count)
    frame["run_id"] = path.stem[2:]
    frame["config"], frame["setup"] = config, setup
    frame["station_ft"], frame["flow"], frame["replicate"] = int(station), flow, replicate
    return frame

Apply an interpolation method — predict_plane

Input: A method name, retained sensor coordinates and speeds, and query coordinates.
Output: One predicted speed per query; linear gives NaN outside the sensor hull.
What it does: Chooses nearest neighbour, linear or thin-plate RBF. It uses the coordinates supplied by the caller; the report workflow supplies training-only standardised coordinates.

def predict_plane(method: str, locations, values, queries) -> np.ndarray:
    """Predict scalar speeds using metre x/y coordinates.

    Parameters
    ----------
    method : str
        nearest, linear, or rbf (thin-plate spline, degree 1, no smoothing).
    locations, queries : array-like
        Finite arrays of shape (n, 2) and (m, 2).
    values : array-like
        Finite scalar training values, shape (n,).

    Returns
    -------
    numpy.ndarray
        Predictions; linear returns NaN outside the training convex hull.
        RBF may extrapolate or predict negative values; no clipping is applied.

    Raises
    ------
    ValueError
        If the method is unknown, arrays have incompatible shapes, values are
        non-finite, or fewer than three unique non-collinear sensors are given.

    Notes
    -----
    This function uses the coordinates supplied by its caller. The nested
    experimental workflow supplies training-only standardised coordinates;
    direct calls may supply metre coordinates. These distance conventions
    should not be mixed when comparing experiments.
    """
    x, q = np.asarray(locations, float), np.asarray(queries, float)
    y = np.asarray(values, float)
    if (x.ndim != 2 or x.shape[1] != 2 or q.ndim != 2 or q.shape[1] != 2
            or y.shape != (len(x),) or len(x) < 3):
        raise ValueError("Expected at least three training points in two dimensions")
    if not all(np.isfinite(a).all() for a in (x, y, q)):
        raise ValueError("Inputs must be finite")
    if len(np.unique(x, axis=0)) != len(x):
        raise ValueError("Duplicate training coordinates")
    if np.linalg.matrix_rank(x - x.mean(axis=0)) < 2:
        raise ValueError("Training coordinates must span a plane")
    if method == "nearest":
        return nearest_neighbor(x, y, q)
    if method == "linear":
        return np.asarray(LinearNDInterpolator(x, y, fill_value=np.nan)(q)).reshape(-1)
    if method == "rbf":
        return RBFInterpolator(x, y, kernel="thin_plate_spline", degree=1, smoothing=0)(q)
    raise ValueError(f"Unknown method: {method}")

def select_plane_svr(x, y, groups=None, grid=None):
    """Tune an SVR using three grouped training-only folds.

    Parameters
    ----------
    x, y : array-like
        Finite training coordinates and speed targets; outer test is excluded.
    groups : array-like, optional
        Location group per row. Defaults to one unique group per coordinate.
    grid : dict, optional
        Predefined C/gamma/epsilon values, independent of outer test targets.

    Returns
    -------
    tuple
        Fitted model, selected parameters, search table and inner split audit.

    Raises
    ------
    ValueError
        If inputs are non-finite or incorrectly shaped, or fewer than three
        training location groups are available.
    RuntimeError
        If an inner or final SVR fit fails its optimisation convergence check.

    Notes
    -----
    The caller must exclude its outer test target before calling. Scaling is
    refitted on each inner training fold, and selection minimises mean inner
    fold RMSE. The predefined search is bounded, not a global optimum claim.
    """
    x,y=np.asarray(x,float),np.asarray(y,float)
    if x.ndim!=2 or x.shape[1]!=2 or y.shape!=(len(x),) or not np.isfinite(x).all() or not np.isfinite(y).all():
        raise ValueError('Finite two-dimensional coordinates and scalar targets required')
    if groups is None:
        _,groups=np.unique(x,axis=0,return_inverse=True)
    groups=np.asarray(groups)
    if len(np.unique(groups))<3:
        raise ValueError('At least three training location groups required')
    grid=grid or DEFAULT_GRID
    splits=list(GroupKFold(n_splits=3).split(x,y,groups))
    rows,audit=[],[]
    for number,(c,g,e) in enumerate(itertools.product(grid['C'],grid['gamma'],grid['epsilon']),1):
        errors=[]
        params=dict(C=c,gamma=g,epsilon=e)
        for fold,(train,validation) in enumerate(splits):
            model,warning=fit_svr(x[train],y[train],groups[train],params)
            if warning or model.named_steps['svr'].fit_status_:
                raise RuntimeError('Inner SVR optimization did not converge')
            error=float(np.sqrt(np.mean((model.predict(x[validation])-y[validation])**2)))
            errors.append(error)
            audit.append(dict(candidate=number,inner_fold=fold,
                              training_indices=';'.join(map(str,train)),validation_indices=';'.join(map(str,validation)),
                              scaler_mean=';'.join(map(str,model.named_steps['standardscaler'].mean_)),rmse=error))
        rows.append(dict(candidate=number,**params,cv_rmse=float(np.mean(errors))))
    search=pd.DataFrame(rows)
    best=search.sort_values(['cv_rmse','candidate']).iloc[0]
    params={k:float(best[k]) for k in ('C','gamma','epsilon')}
    model,warning=fit_svr(x,y,groups,params)
    if warning or model.named_steps['svr'].fit_status_:
        raise RuntimeError('Final SVR optimization did not converge')
    return model,params,search,pd.DataFrame(audit)

def evaluate_experimental_plane(frame,grid=None):
    """Withhold each location before tuning on one independent replicate.

    Parameters
    ----------
    frame : pandas.DataFrame
        One FAA replicate, with unique absolute xyz and scalar speed.
    grid : dict, optional
        Training-only SVR hyperparameter grid.

    Returns
    -------
    tuple
        Outer predictions, search records and nested split/scaler audit.
    """
    if frame.run_id.nunique()!=1 or frame[['x_m','y_m']].duplicated().any():
        raise ValueError('One replicate with unique sensor locations required')
    valid=frame[np.isfinite(frame.speed_mps)].reset_index(drop=True)
    x=valid[['x_m','y_m']].to_numpy()
    y=valid.speed_mps.to_numpy()
    predictions,searches,audits=[],[],[]
    for heldout in range(len(valid)):
        train=np.delete(np.arange(len(valid)),heldout)
        model,params,search,audit=select_plane_svr(x[train],y[train],grid=grid)
        scaler=model.named_steps['standardscaler']
        tx,qx=scaler.transform(x[train]),scaler.transform(x[[heldout]])
        inside=bool(Delaunay(tx).find_simplex(qx,tol=1e-10)[0]>=0)
        for method in METHODS:
            if method=='mean':
                pred=np.array([y[train].mean()])
            else:
                pred=model.predict(x[[heldout]]) if method=='svr' else predict_plane(method,tx,y[train],qx)
            row=valid.iloc[heldout].to_dict()
            row.update(method=method,fold=heldout,prediction_mps=float(pred[0]),inside_hull=inside,
                       target_available=True,train_rows=';'.join(map(str,valid.iloc[train].source_row)))
            if method=='svr':
                row.update(params)
            predictions.append(row)
        for table in (search,audit):
            table['run_id']=frame.run_id.iloc[0]
            table['outer_source_row']=int(valid.source_row.iloc[heldout])
        # Inner indices refer only to these outer training rows, never to test.
        audit['outer_training_source_rows']=';'.join(map(str,valid.iloc[train].source_row))
        audit['outer_scaler_mean']=';'.join(map(str,scaler.mean_))
        searches.append(search)
        audits.append(audit)
    return pd.DataFrame(predictions),pd.concat(searches),pd.concat(audits)

Calculate prediction error — regression_metrics

Input: Reference speeds and predictions at the same supported locations.
Output: RMSE, MAE and signed bias, all in m/s when the inputs are m/s.
What it does: Computes prediction minus observation. Rejects empty, mismatched or non-finite arrays. Positive bias means overprediction.

def regression_metrics(actual: np.ndarray, predicted: np.ndarray) -> dict[str, float]:
    """Return RMSE, MAE and signed mean prediction bias in input units.

    Parameters
    ----------
    actual : numpy.ndarray
        Held-out reference observations, shape (n,).
    predicted : numpy.ndarray
        Predictions at identical locations, shape (n,).

    Returns
    -------
    dict of str to float
        ``rmse``, ``mae`` and ``bias`` (predicted minus actual).

    Raises
    ------
    ValueError
        If arrays are empty, have unequal flattened lengths, or contain
        non-finite values. Restrict to common supported targets explicitly
        before calling; unsupported predictions are not silently dropped.

    Notes
    -----
    Positive bias means overprediction. Opposite errors can cancel in bias
    while RMSE and MAE remain positive. With speeds in m/s, all three metrics
    are in m/s. These metrics do not certify physical validation.
    """
    a = np.asarray(actual, dtype=float).reshape(-1)
    p = np.asarray(predicted, dtype=float).reshape(-1)
    if a.size == 0 or a.shape != p.shape or not np.isfinite(a).all() or not np.isfinite(p).all():
        raise ValueError('actual and predicted must be equal-size finite nonempty arrays')
    err = p-a
    return {
        'rmse': float(np.sqrt(np.mean(err**2))),
        'mae': float(np.mean(np.abs(err))),
        'bias': float(np.mean(err)),
    }

def summarize(predictions):
    """Return coverage and errors on common hull points and extrapolation separately.

    Parameters
    ----------
    predictions : pandas.DataFrame
        Per-fold output from evaluate_plane.

    Returns
    -------
    pandas.DataFrame
        Run/method/subset metrics; counts include unsupported predictions.
    """
    rows = []
    for (run, method), group in predictions.groupby(["run_id", "method"], sort=True):
        for subset in ("common_hull", "outside_hull", "all"):
            selected = group[group.target_available]
            if subset != "all":
                selected = selected[selected.inside_hull == (subset == "common_hull")]
            valid = selected[np.isfinite(selected.prediction_mps)]
            metrics = regression_metrics(valid.speed_mps, valid.prediction_mps) if len(valid) else dict(rmse=np.nan, mae=np.nan, bias=np.nan)
            rows.append(dict(run_id=run, method=method, subset=subset,
                             n_requested=len(selected), n_predicted=len(valid),
                             coverage=len(valid)/len(selected) if len(selected) else np.nan,
                             negative_predictions=int((valid.prediction_mps < 0).sum()),
                             **metrics))
    return pd.DataFrame(rows)
